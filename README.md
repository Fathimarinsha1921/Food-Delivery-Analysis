Food Delivery  Analysis Using SQL

 Project Overview

The **Food Delivery Business Analysis** project focuses on analyzing food delivery business data using SQL and PostgreSQL.

The main objective of this project is to understand business performance by analyzing customer behaviour, order patterns, restaurant performance, revenue generation, and delivery efficiency.

SQL queries are used to transform raw data into meaningful business insights that can help businesses make better decisions.

Project Objectives

- Analyze total orders and revenue.
- Identify the most popular restaurants.
- Understand customer purchasing behaviour.
- Calculate Average Order Value (AOV).
- Analyze monthly revenue trends.
- Identify top-spending customers.
- Evaluate delivery performance.
- Analyze cancelled and pending orders.
- Identify business trends and patterns.

## 📂 Database Structure

**Database Name:** `food_delivery_db`

The database contains five relational tables:

| Table Name | Description |
|---|---|
| customers | Stores customer information |
| restaurants | Stores restaurant details |
| orders | Contains customer order information |
| order_items | Contains ordered food items and quantities |
| deliveries | Stores delivery-related information |

**Total Records:** 465

- Customers: 50
- Restaurants: 15
- Orders: 100
- Order Items: 200

### Important Findings

- Most orders were successfully completed.
- The cancellation rate was 17%, indicating an opportunity to improve order fulfilment.
- Fresh Bites generated the highest revenue among the restaurants.
- Kochi had the highest number of customers.
- The average delivery time was approximately 32 minutes.

7. Execute the analysis queries.
8. Review the results and business insights.
